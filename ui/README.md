# ATS Checker Demo UI

A lightweight, client-side web interface for the ATS Checker library. 100% runs in your browser — no backend, no API key, no data leaves your device.

## Features

- **100% Client-Side & Deterministic** — same resume + JD always produces the same score
- **Real-time Analysis** — instant ATS compatibility scoring
- **Visual Breakdown** — component scores (Skills, Experience, Keywords, Education)
- **Skill Coverage** — matched and missing required skills
- **Keyword Matching** — matched, missing, and overused keywords
- **Experience Parsing** — years parsed from date ranges, gap vs. requirement
- **Detected Sections** — shows which resume sections the parser found
- **Actionable Suggestions** — deterministic improvement recommendations
- **Privacy First** — all data stays on your device

## Quick Start

```bash
npm install
npm run build   # builds library and copies to ui/public/dist/
npm run dev     # serves at http://localhost:3005
```

Or open `ui/public/index.html` directly in any modern browser (works offline).

## Architecture

```
ui/
├── public/
│   ├── index.html      # Self-contained app (HTML + Tailwind + JS)
│   └── dist/
│       └── index.mjs   # Bundled ATS Checker library (generated by npm run build)
└── README.md
```

- **Frontend**: Vanilla HTML/JS with Tailwind CSS (CDN)
- **Library**: Loaded as ES module from `./dist/index.mjs`
- **API used**: `analyzeResume` (sync, deterministic) — no LLM, no async
